# Empleos

Busca empleo en Computrabajo, Tecoloco, LinkedIn, Jooble y Facebook con un toque, y da seguimiento a tus postulaciones.

## Publicarla

1. Crea un repositorio público llamado `empleos` y sube todos estos archivos a la raíz.
2. En **Settings → Pages** elige la rama `main` y la carpeta `/ (root)`.
3. Abre en Chrome `https://tu-usuario.github.io/empleos/` e instálala (necesario para compartir ofertas hacia la app).

## Actualizar la app

Si cambias algún archivo, abre `sw.js` y sube el número de `VERSION` (por ejemplo, de `empleos-v1` a `empleos-v2`).
